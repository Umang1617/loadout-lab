## Important Formatting Notes

- Always use the game's own terminology. Never call Brawl Stars gadgets "items." Never call Genshin Impact artifacts "gear." Use what the game calls them.
- If a game doesn't have one of the standard build slots (e.g. no "gadget" equivalent), remove that row from the table. Don't add placeholder rows.
- If a build option only differs from Option A in one slot, list only the changed slot and write "Same as Option A" for unchanged slots.
- Keep the Character Overview and Why This Works sections as prose paragraphs, not bullet points.
- The How to Play section must be numbered, not bulleted.
- The Source Confidence line is mandatory — never omit it.
